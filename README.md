# FitnessTracker

Aplicatie web pentru monitorizarea activitatilor sportive: antrenamente, obiective si progres.
Proiect pentru materia Programare Multimedia.

## Stadiu
Tema 1 - structura aplicatiei si pagina principala (`index.html`). Celelalte pagini contin o structura de inceput.

## Pagini
- `index.html` - Acasa
- `exercitii.html` - Catalog exercitii
- `antrenamente.html` - Jurnal antrenamente
- `obiective.html` - Obiective
- `progres.html` - Progres si statistici
- `cont.html` - Autentificare / Inregistrare

## Tehnologii
HTML5, CSS3, Bootstrap 5, JavaScript (in etapele urmatoare), baza de date (in etapele urmatoare), Git si GitHub.

## Instructiuni de rulare
1. Descarca sau cloneaza repository-ul.
2. Deschide `index.html` intr-un browser (este necesara conexiune la internet pentru Bootstrap si fonturi).
